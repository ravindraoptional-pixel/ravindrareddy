# Ravindra Reddy — personal site

Static site for GitHub Pages. Open `index.html` locally, or deploy the repository root to `https://ravindraoptional-pixel.github.io`.

## Edit without redesigning

- Email: ravindraoptional@gmail.com (also set in `script.js`)
- Jobs: copy a `<article class="job">` block in `index.html`. Replace every `[ADD …]` field.
- Projects: copy a `<article class="project">` block. Update the number, copy, tags, and links.
- Articles: copy a `<article class="card">` block. Add a matching file in `writing/` or point the link outside.
- Books, skills, certifications: copy the nearest list item or card.

Placeholders are intentional. The previous site did not list employers, dates, or certifications.
